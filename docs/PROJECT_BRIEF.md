# 半导体制造数据中的失效风险与过程漂移

这是一个材料 MSc 背景下的公开数据研究项目：将机器学习的数据清洗、验证和模型分析
方法应用于半导体制造测量，研究历史模型遇到后续数据变化时的可靠性。并非企业项目、
课程评分成果或真实产线部署。实现与文档使用了 AI 辅助，独立掌握程度尚待后续学习验证。

## 问题与方法

UCI SECOM 包含 1,567 条记录、590 个匿名变量及 104 个失败样本。失败少、变量多、
存在缺失，且没有设备、批次与变量物理含义。项目比较逻辑回归、随机森林与简单基线，
在四个时间窗口中使用更早的数据完成选型和阈值选择；所有同时间戳记录保持在同一侧。

## 三个可检查的研究内容

1. **时间泛化。** 最新窗口选中逻辑回归，AP 约 0.185；但另一个仅含 2 个失败样本的
   窗口中 AP 只有约 0.013。保留不稳定结果，并分析误报、概率质量与估计不确定性。
2. **报警诊断。** 检查历史参考期、变量分布、逐变量报警及报警并集。原有两个高报警
   变量在后期通过样本中也出现明显偏移，因此报警不能等同于失败，更不能直接解释根因。
3. **复核取舍。** 最新窗口复核 32 条捕获 5 个失败，也产生 27 个误报；复核 63 条捕获
   6 个失败，误报 57 条。提供捕获、漏报和误报三个按固定规则选出的案例。

另有独立模拟实验，在已知均值突变和缓慢漂移条件下检查监控方法的行为。模拟成功
不代表真实制造过程有效，也不构成真实预警提前量。

## 项目能说明什么

可检查的内容包括 Python 数据处理、可复现实验、时间验证、统计监控与结果解释。
项目目前不证明个人已独立掌握全部代码，不证明真实良率提升、物理根因定位或产线经验。
所有时期均曾被查看，结果属于历史回测；还需要新数据验证和后续个人学习与讲解验收。
